# Published recipes

Recipes that pass review are published here, one folder per author:

```
recipes/<author-name>/<recipe>/recipe.md
```

The path is permanent and carries the author's name. The same recipe appears in the
[Intempt Collective Marketplace](https://intempt.com/recipes) with the author's name on it.

This folder is written by the Intempt team after review. To add a recipe, do not open a pull
request here. Submit it instead:

- from your AI agent, with the setup in the [README](../README.md);
- from the Intempt CLI, with `intempt recipe submit recipe.md`;
- or upload the file at https://intempt.com/recipes/submit.

A person reads every submission and replies within two business days during early access.

Each author keeps the copyright in their recipe. Published recipes are distributed under this
repository's [licence](../LICENSE) with attribution preserved.

To withdraw a recipe, email hey@intempt.com with "Recipe withdrawal, for Somya" and your
submission ID.
